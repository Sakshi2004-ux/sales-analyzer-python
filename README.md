
# Sales Analyzer

A Python data analytics project created while learning Python for Data Analytics.

## Project Overview

This project analyzes sales data using Python and explores sales performance through data cleaning, analysis, and visualization.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Tasks

- Loaded sales data using Pandas
- Explored and cleaned the dataset
- Performed data analysis
- Calculated sales-related metrics
- Created visualizations
- Derived insights from the sales data

## Files

- `SalesAnalyzer.ipynb` - Jupyter Notebook containing the complete analysis
- `SalesData.csv` - Dataset used for the analysis

## How to Run

1. Clone this repository.
2. Open `SalesAnalyzer.ipynb` in Jupyter Notebook or VS Code.
3. Install the required Python libraries if needed.
4. Run the notebook cells.

# Sales Analyzer

A beginner-level Python data analysis project created while learning Python for Data Analytics.

## Project Overview

This project analyzes sales data from a CSV file using Python.

The analysis focuses on calculating sales and cost metrics, comparing revenue across categories and countries, working with dates, and exporting Electronics orders into a separate CSV file.

## Tools & Technologies

- Python
- Jupyter Notebook
- CSV files
- Python `csv` module
- Python `datetime` module

## Project Tasks

The notebook performs the following analysis:

1. Calculate total revenue
2. Calculate total number of orders
3. Calculate total cost
4. Calculate revenue by category
5. Calculate cost by category
6. Calculate revenue by country
7. Find the country with the highest revenue
8. Find the category with the highest revenue
9. Analyze revenue by date
10. Calculate revenue between two dates
11. Export Electronics orders to a separate CSV file
12. Calculate average order value
13. Calculate average cost per order

## Files

- `SalesAnalyzer.ipynb` - Jupyter Notebook containing the complete analysis
- `SalesData.csv` - Dataset used for the analysis
- `electricals.csv` - CSV file containing exported Electronics orders

## Python Concepts Used

- Reading and writing CSV files
- Lists
- Dictionaries
- `for` loops
- `if` conditions
- Functions and variables
- String formatting
- Date handling with `datetime`
- Basic calculations and aggregation

## How to Run

1. Clone this repository.
2. Open `SalesAnalyzer.ipynb` in Jupyter Notebook or VS Code.
3. Make sure Python is installed.
4. Run the notebook cells from top to bottom.
